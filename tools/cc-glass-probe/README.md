# cc-glass-probe

Like `glass-probe`, but the scene is the panel of Control Center: one `NSGlassEffectView` for the panel (280 x 420, r 37) and eight for its controls (pills r 31.5, a square r 24, sliders r 24), over the same test background, once as separate views (`cc-plain`) and once inside an `NSGlassEffectContainerView` (`cc-container`: the shapes melt into one). Saves the PNG of the window and the layer tree. Build and run like glass-probe (`clang -fobjc-arc -o probe main.m -framework Cocoa -framework QuartzCore`, run from a Terminal that has the Screen Recording permission: it calls `screencapture -l`). Captures of a real Mac (macOS 27.0, M1) in `captures/27.0-arm64-cc/`; WindowServer's compositor is fitted on `cc-plain` (`WindowServer/docs/GLASS-CALIBRATION.md`).
